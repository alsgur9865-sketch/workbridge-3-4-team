# Core user flow

```text
Sign up or sign in
-> Select client or freelancer role
-> Complete role profile
-> Client posts a project
-> Freelancer searches and applies
-> Client accepts one applicant
-> Other pending applications are rejected
-> Client proposes final price
-> Freelancer accepts
-> Contract is generated and signed by both parties
-> Client pays through the sandbox gateway
-> Work starts
-> Freelancer submits delivery
-> Client approves completion
-> Platform fee and settlement are recorded
-> Both parties write reviews
```
